# Night Runner

A browser driving game: a night highway, police pursuit, and a garage where every car can be modified
(paint, wheels, aero, carbon, lights, plates, stance and tuning). Built with three.js; it runs entirely in the browser.

## Playing

Open the site in a desktop or mobile browser. It needs an internet connection the first time (three.js and the fonts
load from public CDNs, and each car's model downloads when you pick it).

## What is in this folder

This folder is the published game, generated by a build script; nothing here is edited by hand.

| File | What it is |
| --- | --- |
| `index.html` | The game: physics, cars, garage, audio and HUD |
| `world.js`, `traffic.js`, `pursuit.js`, `rain.js`, `garage.js` | The road, traffic, police, weather and garage room |
| `*-meshopt.txt`, `*-plain.txt`, `tr-*.txt` | Car, traffic and room models (GLB files stored as base64 text) |
| `*.wav` | Engine and effect sounds |
| `tex/`, `keylogo-*.png` | Road textures and the key wall's badges |
